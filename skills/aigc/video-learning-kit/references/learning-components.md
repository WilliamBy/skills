# 学习组件规范

## 共同原则

仅把通过逐句校验的整理稿作为源材料。先通读、建立“章节—核心内容—可考点”地图，再生成指定组件；不要逐句抽样拼接成笔记。

- 使用 `[章节名 · 段N]` 作为定位，可通过 `scripts/source_index.py` 获取段落编号。
- 将讲者主张写成“讲者认为/讲者演示/课程提出”，不要将意见包装成客观事实。
- 对定义、分类、数字和比较，保留原有限定条件。原文没有给定义时，不自行补权威定义。
- 对字幕疑似错误，保留原文并标记“原字幕如此，待音频核验”，不得暗自改成通行术语。
- 不用“显然”“众所周知”等措辞替原文加强断言。
- 同一内容跨组件可复用，但表述目的不同：笔记讲理解，提要抓主线，闪卡促回忆，习题做检索与应用。

## 学习笔记

目标：服务首次系统学习与完整复盘，不是全文压缩替代品。

建议结构：

```markdown
# 《视频名》学习笔记

## 学习地图
- 本课主线：
- 建议学习顺序：

## 一、章节主题
### 核心内容
- [观点/概念/流程，保留条件] [章节 · 段N]
### 论证与例子
- [讲者用什么例子支持什么观点] [章节 · 段N]
### 易混点与待核项
- [只在原文确有歧义或字幕不确定时列出]

## 综合回顾
- [全文主要逻辑链，标注相关章节]
## 待进一步核验
- [术语、数字或事实问题；没有则不写此节]
```

要求：以章节为主线，优先保留概念间关系、论证理由、关键例子、流程步骤、结论边界。删除口播互动不影响学习时可略去，但不删掉承载论点的现场问答。

## 学习提要

目标：5–10 分钟建立全局印象，用于快速浏览、复习前激活记忆。

建议结构：

```markdown
# 《视频名》学习提要

## 一句话主线
[一句仅由原文支持的主线概括]

## 重点地图
| 章节 | 核心问题 | 讲者要点 | 定位 |
|---|---|---|---|

## 必记要点
1. [5–12 条最关键内容，各带定位]

## 关键关系
- [A 与 B 的区别/因果/流程；仅保留原文明确关系]

## 回忆提示
- [3–7 个不带答案的提示问题，引导回到笔记或整理稿]
```

不要写“一文掌握”“全部精华”等夸张标题，不追求把每章平均分配篇幅。

## 记忆闪卡

目标：通过主动回忆巩固最重要的信息，而非把笔记切成小句。

- 默认 12–30 张，用户可指定数量。
- 一卡只测一个目标，问题自足、无歧义，避免“它是什么？”这类脱离上下文的代词。
- 优先使用简答、辨别、条件、流程、因果和反例；避免只考无关紧要的数字或措辞。
- 答案尽量 1–4 句，保留限定条件和讲者立场。
- 对观点类内容，题干写“讲者认为……？”而非暗示普遍正确。
- 不设置“原文是否提到 X”这类只考再认、无助理解的卡。
- 不用问题本身泄露答案，不让两张卡只是机械换词。

默认 Markdown 表格格式：

```markdown
# 《视频名》记忆闪卡

> 用法：先遮住答案口述，再核对并回到出处复读。仅覆盖源字幕明确支持的内容。

| ID | 正面：问题 | 背面：答案 | 出处 |
|---|---|---|---|
| C01 |  |  | [章节 · 段N] |
```

如用户要求 Anki CSV/TSV，再输出 UTF-8 分隔文件，字段为 `Front,Back,Source`；保留 HTML 转义或不使用逗号冲突的字段。不要默认生成未经请求的专用格式。

## 课后习题

目标：促进检索、理解和迁移，不只是重复讲义。

建议比例：

- 40% 检索与理解：核心概念、分类、流程、条件、理由。
- 30% 比较与分析：比较概念、判断论证、解释例子。
- 20% 情境应用：将原文方法用于相近但新的情境；答案只可使用原文原则，明确这是应用练习。
- 10% 反思与核验：识别讲者主张的边界、字幕待核点或需要额外资料的问题；不得捏造所谓标准答案。

```markdown
# 《视频名》课后习题

> 建议先独立作答，再查看答案。题目基于整理稿，应用题不代表视频中的原始案例。

## 一、检索与理解
1. [题目]

## 二、比较与分析
...

## 三、情境应用
...

## 参考答案与出处
### 第1题
- 答案：
- 依据：[章节 · 段N]
- 评分要点：[适合主观题时列出]
```

对反思题提供“参考思考方向”而非唯一答案；对无法从原文回答的题，不编写事实性标准答案。

## 质量检查

交付前逐项检查：

1. 每个事实性答案是否可由定位段落直接支持？
2. 观点是否保留“讲者认为”等归属？
3. 是否因压缩而遗漏“如果/只有/可能/不一定”等关键限定？
4. 闪卡是否一卡一答，且遮住答案后问题仍完整？
5. 应用题是否标记为延伸情境，而非冒充原视频例子？
6. 是否意外引入了外部知识、术语修正或当代资料？
7. 是否明确建议用户先读提要、再读笔记、用闪卡和习题复习，而非把摘要当全文？
